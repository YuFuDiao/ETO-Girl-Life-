# bdsm_dressing

if $ARGS[0] = '':
	*clr & cla
	menu_off = 0
	gs 'core_library', 'setloc', 'bdsm_dressing', ''
	$location_type = 'private'
	!! Role cleared here and set when re-entering to allow for sub and dom usage
	$bdsmclub['role'] = ''
	gs 'stat'

	'<center><img <<$set_imgh>> src="images/locations/city/suburb/bdsm_club/dressingroom.jpg"></center>'
	'一个巨大的更衣室。这里主要供顺从者换上工作人员服装，正因为如此，这里是个安全的空间，不允许玩游戏。'
	'里面有若干个<a href="exec:gt ''wardrobe'', ''start''">衣柜</a>（你可以在里面挑选服装、整理衣物）。'
	'这里有一整柜一整柜属于俱乐部各成员的名牌服装，还有大量你可以使用的<a href="exec:gt ''mirror'',''start''">镜子</a>。'
	*nl
	'你必须在这里设定本次到访的角色，也可以在这里更换角色，但必须穿着符合该角色的服装，否则你只能离开。'
	'顺从者必须穿女仆装或顺从者情趣商店的服装，或者光着身子。'
	'主导者必须穿着至少"昂贵"品质的服装。'

	if PMaid = 1 or PCloStyle3 = 2 or $clothingworntype = 'nude':
		act '进入俱乐部前厅（顺从者角色）':
			$bdsmclub['role'] = 'sub'
			gt 'bdsm_hallway', 'foyer'
		end
	end
	if daystart > bdsmclub['payday'] + 30:
		*nl
		'你没有付费会员资格，所以不能以主导者身份进入俱乐部，你可以从这里直接去办公室缴纳费用。'
		act '去办公室缴纳会员费': gt 'bdsm_mansion', 'office'
	elseif PCloQuality >= 5 and bdsmclub['domtraining'] = 1:
		act '进入俱乐部前厅（主导者角色）':
			$bdsmclub['role'] = 'dom'
			gt 'bdsm_hallway', 'foyer'
		end
	end

	act '前往前厅（未设定角色）': gt 'bdsm_hallway', 'foyer'

	if $clothingworntype <> 'nude':
		act '离开俱乐部': gt 'city_suburbs', 'start'
	end
end
