$loc = 'artstudia'
menu_off = 1
$location_type = 'secluded'

if $ARGS[0] = 'bodimod1':
	minut += 5
	cla
	*clr
	gs 'stat'
	$func('wrap', 'header center b', '庭院')
	'<center><img <<$set_imgh>> src="images/locations/pushkin/artsudvor.jpg"></center>'
	'这个小庭院很开阔，艺术学校经常在这里进行户外创作。偶尔会有一些学生在这里放松或抽烟。'
	act '离开': gt 'ugol'

	if arts = 1:
		act '去艺术工作室': artsb = 1 & gt 'artstudia', 'bodimod2'
	end
end


if $ARGS[0] = 'bodimod2':
	minut += 5
	cla
	*clr
	gs 'stat'
	$func('wrap', 'header center b', '艺术家的工作室')
	'<center><img <<$set_imgh>> src="images/locations/pushkin/artscor.jpg"></center>'
	'通往艺术学校的走廊墙壁上装饰着各种各样的艺术作品。就算门口没有招牌标明这里是学校，光是这条走廊也足以暴露一切。'
	act '离开': gt 'artstudia', 'bodimod1'

	if rand(0, 2) = 0 and arts_day ! daystart:
		'这里聚集了不少学生。有些人已经脱掉了衣服，身上已经被玛夏画上了颜料。'
		'其中一个女孩招呼你过去：“嗨，又见面了，真高兴你再次来加入我们。快，把衣服脱了，玛夏快把 Emilia 画完了。”'
		act '脱光衣服加入他们':
			arts_day = daystart
			if rand(0, 1) = 0:
				gt 'artstudia', 'bodimod3'
			else
				gt 'artstudia', 'bodimod4'
			end
		end
	end
end

	'几个小时后，在经历了一些男人的不少骚扰之后，拍摄项目结束了，你们全都回到了摄影棚。'
