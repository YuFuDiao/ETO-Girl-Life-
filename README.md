# EtO Girl Life 汉化

《Girl Life》（EtO 分支）的简体中文汉化文本仓库。

本仓库**只收录汉化文本本身**：原始游戏的 `.qsp` 文件、英文原文、生成脚本、审计日志与快照均不入库。

## 目录结构

```
translations/
  0000__start.txt
  0001__version.txt
  0002__feature_updates.txt
  ...
  1396__addbuilddate.txt
```

共 1397 个文件，合计约 42 MB。

## 文件命名规则

```
<序号>__<原版文本名>.txt
```

- `<序号>`：4 位十进制编号，与游戏源码中文本出现的顺序一致，用于稳定排序。
- `<原版文本名>`：对应原版游戏 `game.qsp` 中的文本位置/段落名（例如 `start`、`havana_crossfit`、`sex_ev_doggy`）。
- 每个文件对应原版的一个文本段落，一一对应、顺序固定，便于与上游版本逐段比对。

## 文本格式

- 编码：**UTF-8，无 BOM**
- 换行：原样保留（仓库 `core.autocrlf` 为 `false`，不做事先转换，以免改写译文字节）
- 内容中出现 `<<...>>` 插值、`<html>` 类标签、变量名与标点均为**代码**，翻译时不得改动；人名译名需保持一致。

## 与上游的关系

汉化基于《Girl Life》EtO 分支。原版游戏内容、`.qsp` 源代码及其素材的版权归原作者所有；本仓库仅包含译文，供学习与交流使用。
