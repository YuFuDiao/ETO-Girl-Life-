# city_hermitage
!! Please add a blue underlined link on the St. Petersburg city center page as below for the State Hermitage Museum
!! Please add 1 intelligence point and 5 mood points for each visit

!! $loc, $loc_arg structure used to allow events (like natbels dates) to route through these tours.



if $ARGS[0] = 'start':
	menu_off = 0
	minut += 5
	gs 'core_library', 'setloc', 'city_hermitage', 'start'
	gs 'stat'

	'<center><img <<$set_imgh>> src="images/locations/city/citycenter/hermitage/gp1.jpg"></center>'
	'你看到远处就是埃尔米塔日博物馆。它是世界第二大艺术博物馆，由叶卡捷琳娜大帝于1764年创建，自1852年起向公众开放。'
	'这些藏品包括叶卡捷琳娜的收藏，她正是以此创办了这座博物馆。'
	'博物馆主建筑群的六栋建筑中，有五栋向公众开放，分别是冬宫、小埃尔米塔日、旧埃尔米塔日、新埃尔米塔日和埃尔米塔日剧院。'
	'你走向位于冬宫的游客入口。'
end


if $ARGS[0] = 'return':
	menu_off = 0
	minut += 5
	gs 'core_library', 'setloc', 'city_hermitage', 'return'
	gs 'stat'

	'<center><img <<$set_imgh>> src="images/locations/city/citycenter/hermitage/gp1.jpg"></center>'
	'你回到位于冬宫的游客入口。'
	'埃尔米塔日博物馆是世界第二大艺术博物馆，由叶卡捷琳娜大帝于1764年创建，自1852年起向公众开放。'
	'这些藏品包括叶卡捷琳娜的收藏，她正是以此创办了这座博物馆。'
	'博物馆主建筑群的六栋建筑中，有五栋向公众开放，分别是冬宫、小埃尔米塔日、旧埃尔米塔日、新埃尔米塔日和埃尔米塔日剧院。'
end


if $ARGS[0] = 'start' or $ARGS[0] = 'return':
	act '返回市中心': gt 'city_center'

	if hour < 8:
		*nl
		'博物馆还没开门，现在太早了，无法欣赏任何藏品。'
	elseif hour > 17:
		*nl
		'博物馆已经闭馆，你得离开了。'
	elseif hour = 17:
		*nl
		'博物馆正在闭馆，现在太晚了，无法欣赏任何藏品。'
	else
		act '参观金孔雀钟（90分钟）': gt 'city_hermitage', 'peacock'
		act '参观叶卡捷琳娜大帝的艺术收藏（90分钟）': gt 'city_hermitage', 'art'
		act '参观部分精华展品，从国家仪仗大阶梯开始（90分钟）': gt 'city_hermitage', 'highlights'
		act '参观红色展厅（90分钟）': gt 'city_hermitage', 'red_rooms'
	end
end


if $ARGS[0] = 'peacock':
	*clr & cla
	menu_off = 1
	minut += 60
	gs 'exp_gain', 'intel', 5
	gs 'mood', 'raise', 'tiny'
	gs 'stat'
	'<center><img <<$set_imgh>> src="images/locations/city/citycenter/hermitage/gp2.jpg"></center>'
	'你花了一些时间参观各种藏品，包括埃及和古典文物，以及可以追溯到史前时代的各个艺术画廊。'
	'你探头进房间，看到有人在桌前翻阅文件，人们进进出出。他们抬头看向你。'
	'过了一会儿，你决定去参观博物馆的精华展品之一——金孔雀钟。'
	act '金孔雀钟':
		*clr & cla
		minut += 30
		gs 'stat'
		'<center><img <<$set_imgh>> src="images/locations/city/citycenter/hermitage/gp3.jpg"></center>'
		'金孔雀钟是一件大型自动机，内有三个真人大小的机械鸟。它由企业家詹姆斯·考克斯于18世纪下半叶制造，1781年被叶卡捷琳娜大帝购得。如今它是埃尔米塔日博物馆藏品中的著名展品，自1797年从陶里达宫移入以来一直陈列于此。'
		'金孔雀钟的历史始于1777年，当时金斯顿公爵夫人访问了圣彼得堡。格里高利·波将金在上流社会结识了公爵夫人，了解到詹姆斯·考克斯的作品，便委托他为女皇的埃尔米塔日制作一座带时钟的宏伟自动机。'
		'这是当今世界上仅存的两件此类自动机之一，另一件是银天鹅，可在英国巴纳德堡的鲍斯博物馆参观。'
		'这两件作品站在探索<i>生命</i>含义（无论真实还是人造）的最前沿，堪称那个时代的奇迹。'
		'你非常享受这次参观，感到愉悦而平静，也许今天学到了些东西，于是你决定是时候该走了。'
		act '返回访客入口': gt $loc, $loc_arg
	end
end

		'1764年，叶卡捷琳娜大帝购入200多幅油画，由此开始了她的艺术收藏。这批画原本是为普鲁士腓特烈二世搜集的藏品，但他拒绝完成这笔交易。'
		'这批藏品以荷兰和佛兰德斯画派的作品为主，其中包括13幅伦勃朗和11幅鲁本斯的画作，以及许多其他知名画家的作品。'
		'叶卡捷琳娜最初从戈茨科夫斯基手中购得的藏品中，最著名的作品或许要数伦勃朗1636年绘制的《达娜厄》、1624年绘制的《基督下十字架》，以及弗朗斯·哈尔斯1650年绘制的《持手套的年轻人肖像》。这些画作至今仍收藏在埃尔米塔日。'
		'你非常享受这次参观，感到愉悦而平静，也许今天学到了些东西，于是你决定是时候该走了。'
