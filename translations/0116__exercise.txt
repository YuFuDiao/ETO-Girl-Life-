!{This will centralize calls for exercise. For calls where you wish to allow multiple types of exercises, such as a bedroom or yard, use gs 'exercise', 'start'
For direct calls use this format: gs 'exercise', $ARGS[0], ARG[1], $ARGS[2], $ARGS[3], $ARGS[4]
$ARGS[0] is the workout tier and the higher the tier, the greater the workout intensity.
	Values: 'tier1' 'tier2' 'tier3' 'tier4'
ARGS[1] is the time override. By default the tiers are in 15 minute segments. If being called from an event with predetermined time set this to 1
	Values: 0 (default of 15 minutes) 1 (time set to 0, this is legacy code and should not be used)
	Be aware that tier1 and tier2 only count multiples of 15 when the code runs, so 16 and 30 minutes will result in the same number of exercises.
	tier3 and tier4 use 5 minutes as the intervals, so 6 and 10 will give the same number of exercises, but 6 and 11 are different. The base time = 0 is still 15 minutes

$ARGS[2] and on are the stats to be affected by the workout NOTE: use the gs 'exp_gain', 'name of variable' variant, not the pcs_!!!!
	Values: 'stren' 'vital' 'agil' 'sprt' 'react'
	Other stats can be added if desired - for a dance-a-thon you might use gs 'exercise', 'tier1', 0, 'agil', 'danc'
!}
