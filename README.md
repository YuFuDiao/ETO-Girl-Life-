# EtO Girl Life 汉化

《Girl Life》（EtO 分支）的简体中文汉化工程。

本仓库收录两类内容：

1. **汉化文本**（`translations/`）—— 工程侧产物，便于逐段比对与二次校对；
2. **可玩的汉化版游戏文件** —— 通过 [Releases](https://github.com/YuFuDiao/ETO-Girl-Life-/releases) 发布，不占用仓库体积。

原始 `.qsp` 英文原文、生成脚本、审计日志与快照均不入库。

### 附件命名规则

```
Girl-Life-<游戏版本>-zh-<日期>.qsp
```

名称中只使用字母、数字、`.`、`-`、`_` —— 这是 GitHub 附件名允许的字符集（空格与括号会被自动替换）。

### 运行环境与图像包

- 播放器：推荐 **QQSP**（Windows 便携版）。
- **图像包**：`.qsp` 文件本身只包含文字，图片/视频素材在**独立的图像包**里。图片显示不出来、显示占位图时，**先检查图像包是否完整、版本是否与游戏版本对应**。
- 图像包需与游戏同目录（或按播放器要求放置）。

### 常见问题

| 现象 | 说明 |
|---|---|
| 图片不显示 / 显示占位图 | 图像包缺失或版本不符（文字汉化不影响图片路径） |
| 选项点了没反应 | 历史上出现过「选项参数被汉化破坏」的问题（如难度设置的事件几率），已在 2026-10-10 版修复；若仍出现请反馈具体位置 |
| 选项文字显示为一段正文 | 历史上出现过「act 标签被灌入正文」的批量错位，已在 2026-10-10 版修复 |
| `cum_call` 代码错误（彼得等场景） | **原版缺陷**（NPC 未登记进名字表），英文原版同样复现 |
| 生病状态清除后很快复发 | **原版机制**问题 |
| 除拳击外「踢」伤害为 0 | **原版战斗逻辑**问题 |

> 反馈问题时，请附上**位置名 / 区域 / 行号**（游戏报错弹窗里有），便于定位。

## 二、汉化文本

```
translations/
  0000__start.txt
  0001__version.txt
  ...
  1396__addbuilddate.txt
```

共 1397 个文件，合计约 42 MB。文件命名规则：

```
<序号>__<原版文本名>.txt
```

- `<序号>`：4 位十进制编号，与游戏源码中文本出现的顺序一致，用于稳定排序。
- `<原版文本名>`：对应原版游戏 `game.qsp` 中的文本位置/段落名（例如 `start`、`havana_crossfit`、`sex_ev_doggy`）。

每个文件对应原版的一个文本段落，一一对应、顺序固定，便于与上游版本逐段比对。

## 三、文本格式与翻译约束

- 编码：**UTF-8，无 BOM**
- 换行：原样保留（仓库 `core.autocrlf` 为 `false`，不做事先转换，以免改写译文字节）
- 内容中出现 `<<...>>` 插值、`<html>` 类标签、变量名与标点均为**代码**，翻译时不得改动；人名译名需保持一致。

## 四、工程脚本

仓库根目录另有两个本地辅助脚本（不随 release 发布）：

| 脚本 | 用途 |
|---|---|
| `推送到GitHub.ps1` | 提交 `translations/` 改动并推送到本仓库 |
| `发布Release.ps1` | 按日期批量创建 release 并上传 `.qsp` 附件（每个 release 一个附件） |

## 与上游的关系

汉化基于《Girl Life》EtO 分支。原版游戏内容、`.qsp` 源代码及其素材的版权归原作者所有；本仓库仅包含译文，供学习与交流使用。汉化资源免费分享。
